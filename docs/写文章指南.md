# 📝 写文章指南

给 Frank's Notes 写一篇新文章。站点是标准 Hexo（单语言中文）+ hexo-theme-pure 官方主题，写完 `git push` 到 `main` 自动上线。

> **核心约定**：文章是 Markdown + front-matter，放在 `source/_posts/`。

---

## 第 1 步：新建文章

在 `source/_posts/` 新建一个 `.md` 文件，文件名用英文标识（会成为 URL）：

```bash
# 例如：source/_posts/mybatis-tips.md
```

文件开头是 front-matter（两行 `---` 之间），下面是 Markdown 正文：

```markdown
---
title: MyBatis-Plus 踩坑记录
date: 2026-08-20 14:00:00
categories:
  - 技术
tags:
  - MyBatis-Plus
  - Java
description: 记录使用 MyBatis-Plus 时踩过的几个坑与解法。
---

很多人用 MyBatis-Plus ……（正文第一段）

## 第一个坑：条件构造器

正文段落，直接写 Markdown 即可。

- 列表项一
- 列表项二

> 一句值得强调的话（引用块）。

\`\`\`java
// 代码块照常写
QueryWrapper<User> w = new QueryWrapper<>();
\`\`\`
```

**要点**：
- `title` / `date` 必填；`categories` 决定分类页。
- `description` 会作为摘要和 SEO 描述。
- 想手控摘要：在正文里加一行 `<!-- more -->`，其上为摘要。

## 第 2 步：预览

```bash
npm run server    # http://localhost:4000
```

## 第 3 步：发布

```bash
git add -A
git commit -m "post: 新文章 MyBatis-Plus 踩坑记录"
git push
```

push 到 `main` 后，GitHub Actions 自动构建并发布到 https://frank-dev.site ，约 1 分钟生效。

> 首页文章列表、`/archives/`、`/categories/`、`/tags/`、搜索索引、RSS **全部由 Hexo 自动生成**，无需手动维护任何列表。

---

## front-matter 速查

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 文章标题 |
| `date` | ✅ | 发布时间，影响排序与归档（`YYYY-MM-DD HH:MM:SS`） |
| `categories` | 推荐 | 分类 |
| `tags` | 可选 | 标签 |
| `description` | 可选 | 摘要 / SEO |
| `cover` | 可选 | 封面图 URL |
| `updated` | 可选 | 更新时间（不填用 date） |
| `series` / `series_order` | 可选 | 系列文章分组与排序 |

## 常见问题

**Q：想放图片？**
A：放 `source/images/`，正文用 `![说明](/images/xxx.png)` 引用。

**Q：分类/标签是新建的，要额外配置吗？**
A：不用。Hexo 自动扫描 `categories` / `tags` 生成对应页面。

**Q：想让文章出现在首页？**
A：自动的——首页就是全部文章列表，按 `date` 倒序。

**Q：怎么改作品集页？**
A：作品集是普通页面：`source/projects/index.md`，直接编辑 Markdown（项目名/描述/源码链接）。

**Q：怎么改关于页？**
A：头像/简介/社交链接在 `_config.pure.yml` 的 `about` 块；页内正文在 `source/about/index.md`。
