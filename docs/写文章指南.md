# 📝 写文章指南

给 Frank's Notes 写一篇新文章，照着下面 7 步做，`git push` 后自动上线。

> **核心约定**：文章是纯静态 HTML + 中英双语字典（`js/i18n.js`）。
> 新文章**只需要写中文**，英文没写时网站会自动用中文显示，英文可以以后补。

---

## 第 1 步：复制模板

把 `posts/TEMPLATE.html` 复制一份，文件名用英文标识：

```bash
cp posts/TEMPLATE.html posts/你的文章标识.html
# 例如：cp posts/TEMPLATE.html posts/mybatis-tips.html
```

## 第 2 步：替换 `<PREFIX>`

用编辑器打开新文件，全文替换 `<PREFIX>` 为你的文章标识（和文件名一致）：

- `Mybatis-Plus 踩坑记录` → `<PREFIX>` 填 `mybatis-tips`
- 替换后 key 会变成 `mybatis-tips.p1`、`mybatis-tips.title` 这种形式

顺带改掉 `<title>` 和 `<meta name="description">`。

## 第 3 步：写正文

在 `<div class="article-body">` 里写内容，保留每个元素上的 `data-i18n` 属性，**key 的编号按顺序排**：

| 元素 | 写法 | 说明 |
|---|---|---|
| 段落 | `<p data-i18n="my-post.p1">` | p1、p2、p3… 连续编号 |
| 小标题 | `<h2 data-i18n="my-post.h2_1">` | h2_1、h2_2… |
| 列表 | `<li data-i18n="my-post.li1">` | li1、li2… |
| 引用 | `<blockquote data-i18n="my-post.quote">` | 最多一条 |

不需要的元素（列表、引用、某个小标题）直接删掉，key 也就不用写。

## 第 4 步：在字典里补内容（最核心）

打开 `js/i18n.js`，找到结尾标注 `★ 新文章字典从这里添加` 的位置，加一篇：

```js
/* 文章：Mybatis-Plus 踩坑记录 */
"my-post.eyebrow": "技术 · No. 03",
"my-post.title": "Mybatis-Plus 踩坑记录",
"my-post.date": "2026 年 8 月 20 日",
"my-post.p1": "正文第一段……",
"my-post.h2_1": "第一个小标题",
"my-post.p2": "……",
"my-post.li1": "……",
"my-post.li2": "……",
"my-post.h2_2": "……",
"my-post.p3": "……",
"my-post.quote": "……",
"my-post.h2_3": "……",
"my-post.p4": "……",
```

- **zh 字典必写**（就是 `zh: { ... }` 那一块）
- **en 字典可选**（`en: { ... }` 那块）：不写英文，切换 English 时自动显示中文
- key 必须和 HTML 里的 `data-i18n` 完全一致，漏一个那一段就不显示

## 第 5 步：加到文章列表

打开 `blog.html`，复制一条 `post-item`，改三处：

```html
<li class="post-item reveal" data-cat="tech">
  <span class="date">2026-08-20</span>
  <span class="cat" data-i18n="cat.tech">技术</span>
  <h3><a href="posts/my-post.html" data-i18n="my-post.title">Mybatis-Plus 踩坑记录</a></h3>
</li>
```

- `data-cat`：分类标识（essay=随笔 / tech=技术 / project=项目…），决定筛选标签归哪类
- 日期格式 `YYYY-MM-DD`；`cat` 那个 span 用分类键（`cat.essay` / `cat.tech` / `cat.project`）

## 第 6 步：新分类？加一个筛选标签

如果新文章用了还不存在的分类，在 blog.html 的 `.filter-bar` 里加一个按钮，并在 `js/i18n.js` 加分类名：

```html
<button class="filter-btn" data-filter="project" data-i18n="cat.project">项目</button>
```

```js
// i18n.js
"cat.project": "项目",   // zh
"cat.project": "Project", // en
```

## 第 7 步：发布

```bash
git add -A
git commit -m "post: 新文章 xxx"
git push
```

约 1 分钟后自动部署到 https://frank-dev.site（GitHub Pages 自动构建）。

## 常见问题

**Q：正文里想放代码块？**
A：用 `<pre><code>...</code></pre>`，代码是硬编码的，不需要翻译。

**Q：一篇文章很长，key 很多怎么办？**
A：段落多就 p1…p12 一直排，小标题 h2_1…h2_5，编号不影响顺序，只在每个元素自己的 `data-i18n` 里对应好就行。

**Q：想改文章日期？**
A：改两处：文章页 `<span data-i18n="my-post.date">` 对应的字典值，和 blog.html 里的 `date` 文本。

**Q：文章能放图片吗？**
A：可以，图片放 `assets/` 或 `posts/` 下，`<img>` 标签硬编码路径即可。
