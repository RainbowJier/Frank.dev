## 文章结构与内容

1. 按项目既有文章规范补齐 front matter：`title`、日期、`教程` 分类、SSE/WebSocket/实时通信标签、描述、关键词与 `lang: zh-CN`。
2. 用通俗语言说明“实时”的含义，并以简短时间线串起短轮询、长轮询、SSE、WebSocket：每一代解决了什么问题、仍留下什么限制；紧跟演进图和一个最小轮询代码片段。
3. SSE 章节说明其基于普通 HTTP 长连接、`Content-Type: text/event-stream`、事件帧字段（`event`、`data`、`id`、`retry`）和浏览器 `EventSource` 自动重连机制；提供一套完整独立的 Node.js + Express 实战：
   - 初始化目录与安装依赖命令；
   - 完整 `package.json`；
   - 完整 `server.js`（静态页面、SSE 连接、心跳、定时推送、连接关闭清理）；
   - 完整 `public/index.html`（连接、监听消息与自定义事件、状态展示）；
   - 精确的启动命令、浏览器访问地址和预期效果。
4. WebSocket 章节先用配图拆解 HTTP 请求升级过程、关键请求/响应头、状态码 `101`，再说明握手完成后从 HTTP 切换为帧协议及全双工通信；提供另一套完整独立的 Node.js + `ws` 实战：
   - 初始化目录与安装依赖命令；
   - 完整 `package.json`；
   - 完整 `server.js`（HTTP 静态服务与 WebSocket 服务共用端口、欢迎消息、广播、连接/关闭日志）；
   - 完整 `public/index.html`（建连、发送文本、接收消息、关闭与重连状态）；
   - 启动步骤、两个浏览器标签页的互动验证方法与预期效果。
5. 使用一张覆盖协议、通信方向、二进制能力、浏览器重连、代理兼容性、连接成本、典型场景和选型建议的 SSE/WebSocket 对比表，并写出明确的初学者选择口诀。
6. 每个主体部分均以“常见踩坑提醒”收尾，覆盖轮询频率、SSE 缓冲/代理超时/跨域与响应格式、WebSocket `ws/wss` 混用、反向代理 Upgrade 头、心跳和资源清理等高频问题。
7. 在结尾给出本篇可直接记住的总结与下一阶段学习方向，控制正文在约 3000–4000 字的快速入门范围内，代码块不少于 6 个（预计 7–8 个）。
