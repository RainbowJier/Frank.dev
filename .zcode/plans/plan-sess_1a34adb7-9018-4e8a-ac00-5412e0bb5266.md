### 文章内容设计
文章标题采用 `Java 反射：从 Class 对象到运行时调用`，沿用现有 Front Matter 格式：`categories: 教程`、`tags: Java/反射/JVM`、中文描述和 `lang: zh-CN`。正文按“先理解模型、再写代码、最后谈边界”的顺序组织：

1. **反射解决什么问题**：解释编译期类型绑定与运行时发现的差异，说明反射不是“随便访问私有成员”，而是读取和操作类元数据。
2. **`Class<?>` 与类元数据**：介绍 `User.class`、`obj.getClass()`、`Class.forName()` 三种获取方式及初始化差异；插入图 1。
3. **查找构造器、字段、方法和注解**：对比 `get*` 与 `getDeclared*` 的范围，说明继承关系、重载匹配和运行时注解保留策略，并给出可运行的 `User` 示例。
4. **从查找到调用**：完整演示构造对象、读取/修改字段、调用实例方法和静态方法；使用 `trySetAccessible()`，明确 `IllegalAccessException`、`InvocationTargetException`、`NoSuchMethodException` 及模块封装限制；插入图 2。
5. **做一个最小注解驱动执行器**：用 `@Command` 或类似运行时注解扫描方法并按名称调用，展示反射在插件、序列化、依赖注入、测试框架和 RuoYi/Spring 机制中的真实用途，同时避免把示例包装成生产级扫描器。
6. **直接调用与反射怎么选**：强调普通业务路径优先直接调用，框架边界、插件扩展和未知类型场景才使用反射；插入图 3，不使用无实验依据的性能柱状图。
7. **性能、安全与工程实践**：说明 `Method`/`Field` 查找和访问检查的成本，建议缓存成员对象、缩小可访问范围、校验输入、避免把任意类名/方法名直接暴露给外部请求，并提醒 JDK 模块系统的限制。
8. **高频坑与面试速答**：覆盖 `getDeclaredMethod` 不包含父类、重载参数类型必须精确、静态方法目标可为 `null`、异常被 `InvocationTargetException` 包装、`setAccessible` 并非万能等问题；最后给出总结与系列/相关阅读链接。

代码示例会保持 Java 17+ 可运行风格，泛型在 SVG 中进行 XML 转义，文章中的 `{{ }}` 等模板敏感内容放在代码围栏中，避免被 Hexo/Nunjucks 误处理。
