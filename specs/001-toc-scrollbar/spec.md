# Feature Specification: 文章目录独立滚动

**Feature Branch**: `001-toc-scrollbar`

**Created**: 2026-09-22

**Status**: Draft

**Input**: User description: "修复，文章的目录太长，对应目录区域也需要滚动条。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在桌面端浏览长文章目录 (Priority: P1)

读者打开包含较多标题的文章时，目录区域应保持在可用的阅读范围内；当目录条目超过可见高度，读者可以在目录区域内独立上下滚动，访问目录中的任意标题，而不必让目录把页面布局无限向下撑长。

**Why this priority**: 长目录会直接遮挡或挤压文章内容，影响文章导航这一核心阅读功能。桌面端文章页是目录的主要展示场景，因此优先保证该场景可用。

**Independent Test**: 打开一篇包含足够多层级标题、目录高度超过视口的文章，确认目录区域出现可操作的纵向滚动能力；滚动目录到顶部和底部，均能看到对应条目并正常跳转到文章标题。

**Acceptance Scenarios**:

1. **Given** 文章目录条目高度超过当前可用视口，**When** 读者查看文章页，**Then** 目录区域保持在页面可视范围内，不将页面布局无限向下撑长，并提供纵向滚动条或等效的可见滚动提示。
2. **Given** 目录区域存在未显示的条目，**When** 读者仅在目录区域内滚动，**Then** 目录条目可以从第一项浏览到最后一项，文章正文不会被目录滚动操作替换或截断。
3. **Given** 读者点击目录中当前可见的标题链接，**When** 页面执行定位，**Then** 文章仍定位到对应标题，目录的滚动能力不会破坏既有目录跳转行为。

---

### User Story 2 - 在移动端展开并浏览长目录 (Priority: P1)

读者在手机或窄屏设备上展开文章目录时，即使目录很长，也应在目录面板内部滚动浏览，而不是让面板超出屏幕或迫使读者滚动整页寻找目录条目。

**Why this priority**: 移动端可视空间更小，长目录更容易覆盖正文、超出屏幕边界或造成页面无法操作；移动端是目录可用性的同等关键场景。

**Independent Test**: 在窄屏视口打开含长目录的文章，展开目录面板并分别滚动目录顶部、中部和底部，确认所有条目可访问、面板不超出屏幕，且可以关闭目录继续阅读正文。

**Acceptance Scenarios**:

1. **Given** 窄屏设备上目录条目超过目录面板可用高度，**When** 读者展开目录，**Then** 目录面板不超出可视屏幕，并提供可操作的纵向滚动能力。
2. **Given** 读者正在目录面板内滚动，**When** 读者到达目录底部或点击某个条目，**Then** 最后一级目录条目仍可访问，点击后仍能定位到正文对应标题。
3. **Given** 文章目录较短，**When** 读者在桌面端或移动端查看目录，**Then** 目录内容不会出现不必要的大面积空白，既有展开、收起和跳转行为保持不变。

### Edge Cases

- 目录只有一个或少量条目时，不应强制显示一个高度异常的空滚动区域，也不应改变原有目录布局。
- 目录包含多层嵌套、长标题或连续的同级标题时，条目仍应保持可辨识，不能因滚动容器而出现横向溢出。
- 目录高度接近或超过视口高度时，目录顶部和底部条目都必须可通过滚动完整看到；滚动条不能遮挡关键文字或链接的可点击区域。
- 用户在目录区域滚动到边界时，页面正文仍应可以继续滚动，不能因目录区域形成无法脱离的滚动陷阱。
- 文章没有目录时，不应新增空的滚动容器或影响文章页面布局。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 文章目录必须限制在当前页面可用的垂直显示范围内，目录条目超过该范围时不得继续无限延伸页面布局。
- **FR-002**: 当目录内容超过可用高度时，系统必须为目录区域提供独立的纵向滚动方式，使读者能够访问从第一项到最后一项的全部目录条目。
- **FR-003**: 目录区域的滚动操作必须与文章正文滚动相互独立；目录滚动不得隐藏、截断或阻止读者继续阅读正文。
- **FR-004**: 目录条目的既有点击定位、当前标题高亮、展开和收起行为必须继续有效。
- **FR-005**: 独立滚动能力必须同时适用于桌面端固定目录区域和移动端展开目录面板，并适配不同视口高度。
- **FR-006**: 当目录内容未超过可用高度时，目录必须保持紧凑展示，不得因为新增滚动能力产生明显的无意义空白或异常布局。
- **FR-007**: 目录区域不得引入横向溢出；长标题和多层级目录仍须保持可读、可点击。
- **FR-008**: 没有目录的文章不得出现空白目录区域、滚动条或其他由本功能引起的布局变化。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在包含至少 30 个目录条目的长文章测试页中，读者可以通过目录区域访问 100% 的目录条目，且目录区域不会超出当前可视范围。
- **SC-002**: 在桌面端和窄屏端各执行至少 10 次目录内滚动与条目点击操作，100% 的操作都能保留既有标题定位结果，不出现目录链接失效。
- **SC-003**: 长目录场景下，页面不出现由目录造成的横向溢出；正文区域仍可独立上下滚动并到达文章底部。
- **SC-004**: 短目录场景与改动前相比，目录条目间距、展开/收起和定位操作保持可用，且不出现明显的额外空白区域。
- **SC-005**: 目录不存在的文章页面在视觉和交互上不新增可见元素或滚动区域。

## Assumptions

- 目录由文章标题自动生成，现有目录链接、当前项高亮和移动端展开/收起交互属于本功能范围内必须保留的既有行为。
- “对应目录区域”指文章页右侧桌面目录和窄屏设备展开后的目录面板，不包含全页面滚动条或文章正文内部滚动。
- 视口高度会因桌面窗口、手机屏幕和浏览器工具栏变化而变化，目录应根据当前可用空间自适应，而不是依赖单一固定屏幕尺寸。
- 本次修复不改变目录条目的生成规则、文章标题层级或目录开关配置。
- 项目采用本地主题样式进行实现，完成后按项目约定通过构建和本地预览验证视觉与交互效果。
